The Relay Race: Why Agent Handoff Matters

How Baton solves the token tax and context amnesia when switching between AI coding agents.

🧠

Context Loss

When switching from Codex to Claude, the new agent forgets what was already attempted, re-analyzing the entire codebase from scratch.

💸

Token Tax

Dumping 100,000 tokens of raw repository code into every prompt burns credits fast and dilutes reasoning capacity.

🪵

The Baton Solution

A structured, compressed bridge file (.baton/) that passes state from one agent directly to the next like a track relay baton.

Module 03

The Baton Pass Packet: Anatomy of a Handoff

Strict limits, secret redactions, and YAML frontmatter that keep handoffs razor sharp.

📏

The 4,000 Character Ceiling

Baton enforces a hard maximum character count (MAX_HANDOFF_CHARS = 4,000) so handoffs stay dense and useful.

🔒

Automated Redaction

Scans text for OpenAI, Anthropic, AWS, and generic tokens, replacing them with `[REDACTED_API_KEY]` before saving.

🏷️

Structured Contract

Contains active task, finished items, pending work, changed files, warnings, and what NOT to touch.

The Structure of a Baton Pass

Every handoff document is formatted with strict YAML metadata followed by human-readable markdown sections:

CODE (src/main/services/passFormat.ts) 

export const MAX_PASS_FILES = 8;
export const MAX_PASS_BULLETS = 5;
export const MAX_BULLET_WORDS = 16;
export const MAX_HANDOFF_CHARS = 4_000;
PLAIN ENGLISH

Highlight at most 8 primary files to keep focus tight...

Limit list items to 5 bullets per section to prevent endless walls of text...

Cap each bullet at 16 words to force concise, punchy descriptions...

Stop the entire handoff package at 4,000 characters total.

PTY Terminals & Multiplexing: Behind the CLI

How Baton streams interactive terminal sessions and keeps them alive in the background with tmux.

⚡

True PTY Streaming

Baton launches processes inside an emulated pseudo-terminal (PTY) with ANSI color codes and cursor repositioning intact.

🔌

tmux Detach & Reattach

If tmux is installed, Baton runs agents inside a detached session. You can close the app and re-open it without killing the agent!

📜

Log Context Extraction

Baton records raw terminal output to disk, parsing test results, errors, and commands run to automatically summarize in the next pass.

Why tmux Matters for Long Running Jobs

Without tmux, quitting Electron or restarting your computer terminates child processes. With tmux, the session lives independently on the operating system level, waiting for Baton to reattach.

Module 05

Tiered Context: Memory Beyond a Single Handoff

How Baton builds a multi-tier memory architecture to give future agents deep project intelligence.

⚡

Tier 1: Ephemeral Active Context

Short-term state: current task goal, active todos, git status, and the immediate prior handoff.

🏛️

Tier 2: Persistent Knowledge

Long-term knowledge files in `.baton/knowledge/`: architecture, architectural decisions (ADRs), constraints, patterns, and known pitfalls.

🤝

Tier 3: Agent Scoped Memory

Personal and shared notes in `.baton/agents/` so specific agents remember specific quirks across sessions.
