Module 01

The Relay Race: Why Agent Handoff Matters

How Baton solves the token tax and context amnesia when switching between AI coding agents.

🧠

Context Loss

When switching from Codex to Claude, the new agent forgets what was already attempted, re-analyzing the entire codebase from scratch.

💸

Token Tax

Dumping 100,000 tokens of raw repository code into every prompt burns credits fast and dilutes reasoning capacity.

🪵

The Baton Solution

A structured, compressed bridge file (.baton/) that passes state from one agent directly to the next like a track relay baton.

The Metaphor: The Emergency Room Patient Chart

When hospital shifts change, doctors don't make the incoming doctor read the patient's lifetime medical records. They hand over a standardized shift chart: vitals, diagnosis, medications given, and next steps.

💡
The Universal CS Insight: Signal-to-Noise Ratio

In LLM prompting, raw size hurts reasoning. By summarizing 10,000 lines of git logs into 8 bullet points, the downstream agent focuses 100% of its attention on the remaining bugs.
