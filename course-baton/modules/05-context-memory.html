Module 05

Tiered Context: Memory Beyond a Single Handoff

How Baton builds a multi-tier memory architecture to give future agents deep project intelligence.

⚡

Tier 1: Ephemeral Active Context

Short-term state: current task goal, active todos, git status, and the immediate prior handoff.

🏛️

Tier 2: Persistent Knowledge

Long-term knowledge files in `.baton/knowledge/`: architecture, architectural decisions (ADRs), constraints, patterns, and known pitfalls.

🤝

Tier 3: Agent Scoped Memory

Personal and shared notes in `.baton/agents/` so specific agents remember specific quirks across sessions.

The ContextCompiler in Action

Watch how `ContextCompiler.ts` fetches and layers the three tiers in parallel:

CODE (src/main/services/ContextCompiler.ts) 

const [overview, arch, decisions, constraints] =
  await Promise.all([
    this.knowledge.getDoc(projectPath, "overview"),
    this.knowledge.getDoc(projectPath, "architecture"),
    this.knowledge.getDoc(projectPath, "decisions"),
    this.knowledge.getDoc(projectPath, "constraints")
  ]);

How to Steer Your AI Like a Senior Engineer

Now that you know how Baton compiles context, you can direct AI coding agents with surgical precision:

"Update .baton/knowledge/decisions.md" Tell your agent to log why an architectural choice was made so the next agent doesn't undo it.
"Keep handoff under 200 words" Ensure summary signal stays high and doesn't crowd out code tokens.
"Check git diff first" Ground the incoming agent in exact changed files before asking for fixes.
